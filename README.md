### 2. AI SRE Assistant

生成AI を活用した、  
システム障害発生時の原因分析や対応支援を行うシステムです。  

#### 2-1. 概要

主に以下の技術を使用して、  
エラーの観測事象・原因仮説・推奨アクションを段階的に生成して通知するシステムを構築しました。  

- AWS Bedrock
- Step Functions
- Prompt Chaining
- Agent Loop

#### 2-2. 特徴

- Prompt Chaining による複数 LLM のオーケストレーション
- Agent Loop による回答の信頼度ベースの再推論フローの構築
- 保守運用を想定した回答品質評価と継続改善の仕組みを設計
